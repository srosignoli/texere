# Sitting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the end of a Sitting out of `ReadingView.svelte` into a tested backend module, `internal/sitting`. This also fixes peeks rescheduling the Source and the notes save overwriting the `# @progress` marker.

**Architecture:** A `sitting.Tracker`, owned by `collection.Session`, holds the open Sitting in memory. The Tracker serialises Begin, Progress and End under one lock, and owns the end order: notes, then marker, then reading time, then reschedule. Three thin Wails bindings replace `UpdateReadingProgress`, `LogReadingSession` and `RescheduleReading`. `ReadingView` and `StudySurface` drop their copies of the policy.

**Tech Stack:** Go 1.25 (`go.mod`), `database/sql` SQLite via `internal/learning`, Wails v2, Svelte 3.49.

**Spec:** `docs/superpowers/specs/2026-10-21-sitting-design.md`. Read it first; decisions are cited as **D1–D14**.

## Global Constraints

- Branch `103-sitting`. In a worktree, copy `frontend/dist` in first (go:embed needs it).
- `internal/sitting` must not import the Wails runtime or `internal/collection` (**D1**, **D3**).
- No new dependencies. No CGo.
- Valid actions are exactly `continue`, `later`, `done`. `later` schedules like `continue` and must not be special-cased (out of scope).
- Reading time is logged as `LogActivity("read", sourceID, "", seconds, now)`, and only when `seconds > 0` (**D10**).
- Vocabulary is from `CONTEXT.md`: Sitting, Source, Extract, Session. Do not name anything "reading session".
- Imports are grouped stdlib / external / internal, and the code is `gofmt`-clean. `make test`, `make lint` and `make test-js` pass at every commit.

## Review Focus

1. **A notes save that keeps failing** (e.g. the notes file was deleted or made read-only during the Sitting). Per D9 the Sitting stays open, so a user pressing × again would be stuck. Expected: the second close after an error asks "Close without saving notes?" and ends the Sitting with `notes == nil`. *(Owned by Task 5.)*
2. **A pane that never reports a position** (no `getProgress`, no pushes). Expected: End writes no marker and sets no position, but still logs time and reschedules. *(Test in Task 2.)*
3. **A Wails call arriving after the Collection closed.** Expected: an `EndSitting` from a destroyed view returns `collection.ErrNoCollection` or no-ops, and never panics on a closed store. *(Test in Task 4.)*
4. **An unknown action string** (a typo in a caller). Expected: End returns an error and the Sitting stays open, with nothing written. *(Test in Task 2.)*
5. **Begin on a Source whose stored notes path escapes the Collection** (a copied Collection with legacy absolute paths). Expected: Begin fails, and nothing is written anywhere. *(Migrated test in Task 4.)*

### Task 2: `sitting.Tracker`: Begin, Progress, End for a normal Sitting

**Files:**
- Create: `internal/sitting/doc.go`, `internal/sitting/tracker.go`, `internal/sitting/tracker_test.go`

**Interfaces:**
- Consumes: `learning.Store` (`GetReading`, `SetReadingProgress`, `ApplyReadingSchedule`, `LogActivity`, `Resolve`), `learning.ScheduleReading`, `content.UpdateProgressMarker`.
- Produces:
  ```go
  type Deps struct {
      Store     *learning.Store
      SelfWrite func(path string, fn func() error) error
      SaveNotes func(path, text string) (final string, err error)
      Now       func() time.Time // nil = time.Now
  }
  func New(d Deps) *Tracker
  func (t *Tracker) Begin(sourceID, peekAnchor string) (sittingID string, src learning.ReadingElement, err error)
  func (t *Tracker) Progress(sittingID, position string) (sourceID string, err error)
  func (t *Tracker) End(sittingID, position, action string, notes *string) (finalNotes string, err error)
  var ErrNoSitting = errors.New("sitting: no such open sitting")
  ```
  `src.NotesPath` comes back **resolved (absolute)**. `Progress` returns `ErrNoSitting` for an unknown id. `End` on an unknown or ended id returns `("", nil)`. `finalNotes` is `""` when `notes == nil`. `position == ""` means "no position reported".

Test fixture: `newFixture(t)` builds a temp Collection with `content.CreateReadingNotes` and a row with `NotesPath: "reading/k.n4l"` (relative), `Position: "char=0"` and `IntervalDays: 1`. It returns a Tracker whose `Now` is a settable clock, `SelfWrite` runs fn directly, and `SaveNotes` writes the text verbatim and returns it.

  - `TestBeginUnknownSourceFails`: an error, and no Sitting opened (a later `Progress` gives `ErrNoSitting`).
  - `TestEndContinueLogsTimeReschedulesAndWritesMarker`: Begin, advance the clock 600 s, `End(id, "char=500", "continue", nil)`. Then `GetReading` has `Position == "char=500"`, `IntervalDays == 2`, `LastRead` equal to the clock, and `Due` = clock + 48h. The notes file contains `# @progress char=500`, and `ActivityWeeks("read",1,clock)[0].Count == 10`.
  - `TestMarkerSurvivesTheNotesSaveAtEnd`: notes text = the original file (still `# @progress char=0`) plus an edit. After `End(id, "char=500", "continue", &text)`, the file has the edit **and** `# @progress char=500`.

  - `TestEndWithoutAnyPositionWritesNoMarker` (Review Focus 2): the file is unchanged, the time is logged, and the Source is rescheduled.
  - `TestEndTwiceLogsTimeOnce`: two Ends, and the activity count reflects one Sitting.
  - `TestEndZeroSecondsLogsNothing`: `ActivitySince("")` reports `ok == false`.
  - `TestEndDoneMarksDoneWithoutRescheduling`: `Done == true` and `IntervalDays` unchanged.
  - `TestEndUnknownActionKeepsTheSittingOpen` (Review Focus 4): `End(id, "char=9", "soon", nil)` returns an error, the file and row are unchanged, and a following valid End succeeds.

- [ ] **Step 3: Implement** in `tracker.go`. One `sync.Mutex` guards a single `open *sitting`, which holds `{id, sourceID, notesPath, peek bool, started time.Time, lastPos string}`. Ids come from `content.GenerateShortID()`. Validate the action before any write. End order (**D5**), with `lastPos` updated from the `position` argument first:
  1. if `notes != nil`: `SelfWrite(notesPath, SaveNotes)`. On error, return it and leave the Sitting open (**D9**);

  4. `ApplyReadingSchedule(ScheduleReading(fresh row, action, now))`.
