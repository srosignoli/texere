# N4L Linter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Files the parser misreads are visible — a red `!` beside the filename and a Problems tab explaining what happened and how to fix it — without imposing syntax rules on a format meant for casual notes.

**Architecture:** A classification table over the `ParseError` values the parser already produces. No new detection, so the linter cannot disagree with the parser about what N4L is. Findings split into per-file *defects* (which mark a file) and collection-level *vocabulary* (which never does).

**Tech Stack:** Go 1.25, Svelte 3.49, Wails v2, `node:test`. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-08-20-n4l-linter-design.md`

## Global Constraints

- **Add no detection logic.** Every finding comes from a `ParseError` the parser already emits. If a check is not already in `internal/content/parser.go`, it is out of scope.
- **Every `ParseError.Msg` is `<Err constant> + ": " + detail`** — verified at all nine production sites. Classification is prefix matching on the constants in `internal/content/errors.go`.
- **`ErrUnknownArrow` formats the arrow with `%q`**, so its detail is quoted: `unknown arrow: "has-frag"`. Strip the quotes when aggregating by name.
- **`ErrOrphanDitto` is declared but never produced** — verified: `grep -rn ErrOrphanDitto --include="*.go"` returns only its declaration. Include it in the classification table defensively, but do NOT write a fixture for it; it is unreachable today.
- **`make test-js` runs `node --test frontend/src/lib/*.test.js`**; `make test` runs `go test ./...`.
- **Never introduce a literal colour** (`frontend/src/lib/theme-tokens.test.js` fails on any) **and no emoji** (`frontend/src/lib/icons.test.js` fails on astral-plane characters). BMP symbols such as `⚠` and `!` are fine.
- **Measured baseline on the real collection**, for sanity-checking your own runs: 53 files, 145 ms, 35,184 findings — 34,970 `unknown arrow` across **158 distinct names**, 174 `unterminated quote`, 40 `unresolved reference`. Defects affect **7 files**; vocabulary affects 39.
- Do not open or modify the user's real collection at `/home/simone/projects/SStorytimeFork/SStorytime-main/examples/test`. Use a copy.

```go
type LintCategory int
const (
    CategoryDefect     LintCategory = iota // parser produced something other than what was written
    CategoryVocabulary                     // an undeclared arrow; never marks a file
    CategoryUnknown                        // unrecognised Msg prefix
)

// Classify maps a ParseError to its category by matching Msg against the Err*
// constants in errors.go.
func Classify(e ParseError) LintCategory

// Remediation returns the "what to do about it" half for a ParseError, or ""
// when there is nothing useful to say.
func Remediation(e ParseError) string

// ArrowName extracts the arrow from an ErrUnknownArrow message, unquoting it.
// Returns "" for any other kind.
func ArrowName(e ParseError) string
```

```go
package content

import "testing"

func perr(msg string) ParseError { return ParseError{File: "x.n4l", Line: 3, Msg: msg} }

func TestClassifyDefects(t *testing.T) {
	// Every kind that means "the parser produced something other than what was
	// written". These are the ones that mark a file.
	for _, msg := range []string{
		ErrUnterminatedQuote + ": quoted block opened here is never closed",
		ErrUnresolvedRef + ": $PREV.2",
		ErrMalformedMarker + ": # @card bogus",
		ErrInvalidPriority + ": 9",
		ErrEncoding + ": invalid utf-8",
	} {
		if got := Classify(perr(msg)); got != CategoryDefect {
			t.Errorf("Classify(%q) = %v, want CategoryDefect", msg, got)
		}
	}
}

func TestClassifyVocabulary(t *testing.T) {
	// An undeclared arrow is not a defect: the note is fine, the relation just
	// will not become a graph edge. 99.4% of findings on the real collection are
	// this, and treating them as defects would mark 39 of 53 files.
	if got := Classify(perr(ErrUnknownArrow + `: "has-frag"`)); got != CategoryVocabulary {
		t.Errorf("got %v, want CategoryVocabulary", got)
	}
}

func TestClassifyUnrecognised(t *testing.T) {
	if got := Classify(perr("something the parser grew later")); got != CategoryUnknown {
		t.Errorf("got %v, want CategoryUnknown", got)
	}
}

// The parser formats the arrow with %q, so the detail is quoted. Aggregating by
// name without unquoting would produce two entries for the same arrow.
func TestArrowNameUnquotes(t *testing.T) {
	if got := ArrowName(perr(ErrUnknownArrow + `: "has-frag"`)); got != "has-frag" {
		t.Errorf("got %q, want %q", got, "has-frag")
	}
}

func TestArrowNameOnNonArrowIsEmpty(t *testing.T) {
	if got := ArrowName(perr(ErrUnresolvedRef + ": $PREV.2")); got != "" {
		t.Errorf("got %q, want empty", got)
	}
}

// Remediation must exist for every kind a user can actually hit, or the
// Problems tab shows a problem with no advice.
func TestRemediationExistsForEveryLiveKind(t *testing.T) {
	// ErrOrphanDitto is deliberately absent: it is declared in errors.go but
	// never produced anywhere (verified by grep), so it is unreachable.
	for _, k := range []string{
		ErrUnknownArrow, ErrUnterminatedQuote, ErrUnresolvedRef,
		ErrMalformedMarker, ErrInvalidPriority, ErrEncoding,
	} {
		if Remediation(perr(k+": detail")) == "" {
			t.Errorf("no remediation for %q", k)
		}
	}
}
```

```go
type LintDefect struct {
    File        string `json:"file"`        // collection-relative
    Line        int    `json:"line"`
    Kind        string `json:"kind"`
    Message     string `json:"message"`
    Remediation string `json:"remediation"`
}

type LintVocabulary struct {
    Arrow string   `json:"arrow"`
    Uses  int      `json:"uses"`
    Files []string `json:"files"` // collection-relative, sorted
}

type LintResult struct {
    Defects    []LintDefect     `json:"defects"`
    Vocabulary []LintVocabulary `json:"vocabulary"` // sorted by Uses descending
    FilesLinted int             `json:"filesLinted"`
}

func LintCollection(dir string, reg *SSTRegistry) (LintResult, error)
```

```go
func TestLintFixturesProvokeTheirKind(t *testing.T) {
	reg := &SSTRegistry{Arrows: map[string]ArrowDef{}}
	for file, wantKind := range map[string]string{
		"testdata/lint/malformed-marker.n4l": ErrMalformedMarker,
		"testdata/lint/invalid-priority.n4l": ErrInvalidPriority,
		"testdata/lint/bad-encoding.n4l":     ErrEncoding,
	} {
		pf, perrs := ParseFile(file, reg)
		all := append([]ParseError{}, perrs...)
		if pf != nil { all = append(all, pf.Errors...) }
		found := false
		for _, e := range all {
			if strings.HasPrefix(e.Msg, wantKind) { found = true }
		}
		if !found {
			t.Errorf("%s did not produce %q; got %v", file, wantKind, all)
		}
	}
}

// The aggregation property that makes the feature usable: on the real
// collection 34,970 occurrences are only 158 causes. Two files using the same
// undeclared arrow must produce ONE vocabulary row, not two.
func TestLintAggregatesArrowsByName(t *testing.T) {
	dir := t.TempDir()
	// "wibbles" is in neither file's registry, so every use is an unknown arrow.
	mustWrite(t, filepath.Join(dir, "a.n4l"), "- ch\n\nalpha\n    (wibbles) beta\n")
	mustWrite(t, filepath.Join(dir, "b.n4l"), "- ch\n\ngamma\n    (wibbles) delta\n    (wibbles) epsilon\n")

	reg := &SSTRegistry{Arrows: map[string]ArrowDef{}}
	res, err := LintCollection(dir, reg)
	if err != nil {
		t.Fatal(err)
	}
	if len(res.Vocabulary) != 1 {
		t.Fatalf("want 1 vocabulary row, got %d: %+v", len(res.Vocabulary), res.Vocabulary)
	}
	v := res.Vocabulary[0]
	if v.Arrow != "wibbles" {
		t.Errorf("arrow = %q, want %q (is it still quoted?)", v.Arrow, "wibbles")
	}
	if v.Uses != 3 {
		t.Errorf("uses = %d, want 3 — occurrences must be summed across files", v.Uses)
	}
	if len(v.Files) != 2 {
		t.Errorf("files = %v, want both a.n4l and b.n4l", v.Files)
	}
}

// The split the whole design rests on. A file with both kinds must yield the
// quote as a defect and the arrow as vocabulary — never the arrow as a defect,
// which is what would mark 39 of 53 real files instead of 7.
func TestLintDefectsAndVocabularyAreSeparate(t *testing.T) {
	dir := t.TempDir()
	mustWrite(t, filepath.Join(dir, "mixed.n4l"),
		"- ch\n\nalpha\n    (wibbles) beta\n\n\"an unterminated quote\n")

	reg := &SSTRegistry{Arrows: map[string]ArrowDef{}}
	res, err := LintCollection(dir, reg)
	if err != nil {
		t.Fatal(err)
	}
	if len(res.Vocabulary) != 1 || res.Vocabulary[0].Arrow != "wibbles" {
		t.Errorf("vocabulary = %+v, want one entry for wibbles", res.Vocabulary)
	}
	for _, d := range res.Defects {
		if strings.HasPrefix(d.Kind, ErrUnknownArrow) {
			t.Errorf("an undeclared arrow was reported as a defect: %+v", d)
		}
	}
	var quotes int
	for _, d := range res.Defects {
		if strings.HasPrefix(d.Kind, ErrUnterminatedQuote) {
			quotes++
		}
	}
	if quotes != 1 {
		t.Errorf("want 1 unterminated-quote defect, got %d: %+v", quotes, res.Defects)
	}
}

func mustWrite(t *testing.T, path, body string) {
	t.Helper()
	if err := os.WriteFile(path, []byte(body), 0o644); err != nil {
		t.Fatal(err)
	}
}
```

- [ ] **Step 1: Add the tab bar**

`LogPanel.svelte` today is a flat list of `$logEntries` with severity filter chips. Add a tab bar with **Log** (everything currently there, unchanged) and **Problems**.

The two are different in kind and must not share storage: `logEntries` is an append-only history written by `appendLog` from several call sites; the lint result is current state replaced on every run. Appending findings into the log would duplicate them on every re-lint and leave fixed problems visible forever.

- [ ] **Step 2: The Problems view**

Two sections:

1. **Defects** — grouped by file, each showing line, message and remediation. This is what the marker refers to; clicking a file should be possible later, but opening the file at the line is **not** in scope here.
2. **Vocabulary** — undeclared arrows, sorted by use count, each showing the count and the files it appears in, with the remediation (declare it in SSTconfig). On the real collection this is 158 rows, so it needs to be scannable — the two importer arrows at the top account for 16,906 of 34,970 uses.

Use existing tokens only. Read `QueryHelpPanel.svelte` for the panel-content idiom this repo uses.

Empty state matters: a collection with no defects should say so plainly, not render an empty box.

- [ ] **Step 3: Re-lint on save**

After a successful save, re-run the lint and replace the store. This is what makes a fixed problem disappear, which is the whole reason the result is state rather than history.

**Type consistency:** `LintCategory`, `Classify`, `Remediation`, `ArrowName` are introduced in Task 1 and consumed in Task 2 with those exact names. `LintResult` / `LintDefect` / `LintVocabulary` are defined in Task 2 and consumed by Tasks 3-4 through the Wails binding with the JSON field names given.

**Verified before writing, not assumed:** every `ParseError.Msg` is `<Err constant> + ": " + detail` at all nine production sites, so prefix matching is uniform; `ErrUnknownArrow` uses `%q` so its detail is quoted and must be unquoted when aggregating; **`ErrOrphanDitto` is declared but never produced** (`grep -rn ErrOrphanDitto --include="*.go"` returns only its declaration), so the plan requires no fixture for it — the spec's "four untested kinds" is really three plus one unreachable constant; a full-collection lint measured 145 ms.

**Known weakness this plan accepts:** the marker and the Problems tab have no automated coverage — this repo has no Svelte component harness, and the guard tests it does have cover colours, icons and shortcuts, none of which is what changed. Task 5 is the only check that the marker appears on the right files, and its strongest single assertion is the baseline comparison: 7 files, not 39. If that number drifts, the classification is wrong regardless of what the Go tests say.
